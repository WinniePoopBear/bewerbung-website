# Portfolio Website

A modern, responsive portfolio website showcasing my projects, technical skills, and professional background.

The website was built to serve as my personal portfolio and accompanies my job applications by providing an overview of my experience, technologies, and software projects.

## Features

- Responsive design
- German and English language support
- Modern UI
- Project showcase
- Skills overview
- Contact section
- Legal notice and privacy pages

## Tech Stack

- React
- Vite
- JavaScript
- CSS3
- React Router

## Live Demo

http://lars-winterling.cleetus.de

## Installation

Clone the repository:

```bash
git clone https://github.com/WinniePoopBear/bewerbung-website.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
